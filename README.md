# SyManager Community

SyManager is an iPhone and iPad app for managing a Synology NAS running DSM 7.

This is the place to:

- **Report a bug:** [open a bug report](https://github.com/symanager/community/issues/new?template=bug_report.yml)
- **Ask for a feature:** [suggest a feature](https://github.com/symanager/community/issues/new?template=feature_request.yml)
- **Ask a question or share tips:** [Discussions](https://github.com/symanager/community/discussions)

Before opening a new issue, please [search the existing ones](https://github.com/symanager/community/issues?q=is%3Aissue). Someone may have reported it already; add a 👍 to it instead.

## Keep your NAS private

Issues and discussions are public. Never post:

- passwords, 2FA codes or recovery codes
- your QuickConnect ID, public IP address or domain names
- screenshots that show serial numbers, MAC addresses, user names or file names you'd rather keep private

Blur or crop screenshots before attaching them.
